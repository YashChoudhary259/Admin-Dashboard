# Admin Dashboard

An **Admin Dashboard** built as part of [The Odin Project](https://www.theodinproject.com/) curriculum.  
This project focuses on practicing **HTML, CSS (Grid, Flexbox)**, and layout design by creating a fully responsive and organized dashboard interface.

---

## 📌 Features

- **Responsive Layout** using CSS Grid and Flexbox
- **Sidebar Navigation** with icons and links
- **Header Section** with search bar and user profile area
- **Main Content Area** displaying:
  - Project cards
  - Announcements
  - Trending section
- **Hover effects** and consistent color theme

---

## 🎯 Skills Practiced

- Semantic HTML structure
- CSS Grid for complex layouts
- Flexbox for smaller layout components
- Positioning and alignment
- Working with icons (SVGs or icon libraries)
- Organizing CSS for large projects

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- [Google Fonts](https://fonts.google.com/) (for typography)
- [Material Icons](https://fonts.google.com/icons) / SVG icons
